# Estudo de tipografia e navegação: Georgia + Manrope

Amostras feitas na renderização local do frontend React da `dev/tasks-workspace`, sem autenticação operacional, sem dados sensíveis e **sem alterar arquivos do código ou publicar deploy**.

- Marca Backoffice: Georgia, 16px, peso 400, mesma família serifada dos títulos do login.
- Navbar superior e sidebar: Manrope 12,5px, peso 500, ativo 600; altura 44px submódulos, 40px menu lateral.
- Sol/Lua: botão original de um clique **de volta ao canto direito da navbar**, preservando ícone, rótulo e comportamento.
- Duas propostas comparadas: `cards` (todos os itens com o acabamento de Carteiras) e `active` (somente módulo selecionado com contorno semelhante ao seletor de Carteiras).
- A opção `active` é visualmente mais limpa e é a recomendação de design para manter a linguagem editorial premium do login.
- O seletor Carteiras original, organização dos módulos e posição de Usuários/Sair permanecem como anteriormente.
- Manrope foi carregada somente para gerar esta prévia, sem adicionar fonte externa ou arquivo de fonte ao repositório do usuário.

A autenticação real, segregação da aba administrativa e navegação funcional não são representadas por estes screenshots. A página de Pagamentos corresponde ao componente original sem carregar dados operacionais.
